# Condivisi

Codice riusabile da più giochi. Ogni modulo entra qui solo quando serve a un gioco reale
(non si scrive codice "per il futuro").

Moduli previsti:

| Modulo | Contenuto | Primo gioco che lo usa |
|---|---|---|
| `rete/` | Stanze online, codice invito, sincronizzazione stato host → client | Caccia a Pac-Man |
| `comandi/` | Tastiera, swipe e joystick virtuale con un'unica interfaccia | Caccia a Pac-Man |
| `audio/` | Effetti sonori generati da codice (jsfxr) | Caccia a Pac-Man |
| `pwa/` | Manifest e service worker per installare il gioco come app | Caccia a Pac-Man |
